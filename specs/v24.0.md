# Especificaciones v24.0 (Envíos e Integración en la Nube)

## Módulo de Envíos
- Conexión directa con APIs de correo.
- Integración con Gmail API.
- Integración con Microsoft 365 / Outlook API.
- Soporte para envíos vía SMTP personalizado.
- Gestión de listas de distribución o contactos básicos.

## Asistente Inteligente (IA)
- Asistente integrado para generar estructuras de correos y textos.
- Inputs simples: "Invitación para cursos del tercer periodo".
- Generación automática de: Asunto, banner sugerido, cuerpo, botones y pie de firma.

## Sincronización en la Nube
- Migrar el almacenamiento local (`localStorage`) a una base de datos real (ej. Firebase, Supabase o Cloud SQL).
- Cuentas de usuario para guardar proyectos y plantillas en la nube.
